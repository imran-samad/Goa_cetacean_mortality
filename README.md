# Goa cetacean mortality analysis

This repository contains the analytical workflow used to quantify cetacean mortality in Goa, with a focus on stranding data, distance-sampling density estimation, stranding-probability estimation, Bayesian mortality modelling, and spatial mapping of inferred mortality hotspots.

## Overview

The project is organised around a sequence of analytical steps:

1. data exploration and quality checks,
2. density estimation from survey data,
3. estimation of stranding probability from particle trajectories,
4. Bayesian monthly mortality modelling,
5. spatial mapping of inferred mortality risk.

The code is split across individual analysis files, and each one is paired with a rendered Markdown report.

## File map

### 1. Data exploration
- [Code/1_Data_exploration.qmd](Code/1_Data_exploration.qmd)
- [Results/1_Data_exploration.md](Results/1_Data_exploration.md)

This document summarises the stranding dataset, compares reviewer estimates with self-reported decomposition and PMI values, and provides initial spatial summaries of the survey and boat-activity data.

### 2. Density estimation
- [Code/2_Density_estimation.qmd](Code/2_Density_estimation.qmd)
- [Results/2_Density_estimation.md](Results/2_Density_estimation.md)

This analysis estimates dolphin density from line-transect or distance-sampling data, including covariate handling and survey-specific model fitting.

### 3. Estimating stranding probability
- [Code/3_Estimating_stranding_prob.qmd](Code/3_Estimating_stranding_prob.qmd)
- [Results/3_Estimating_stranding_prob.md](Results/3_Estimating_stranding_prob.md)

This workflow estimates coastal stranding probability by combining particle trajectories with the coastline grid and summarising the probability that a mortality event reaches shore.

### 4. Modelling mortality
- [Code/4_Modelling_mortality.qmd](Code/4_Modelling_mortality.qmd)
- [Results/4_Modelling_mortality.md](Results/4_Modelling_mortality.md)

This document implements the Bayesian monthly mortality model that adjusts observed strandings by the stranding probability and estimates latent monthly and annual mortality.

### 5. Mapping mortality
- [Code/5_Mapping_mortality.qmd](Code/5_Mapping_mortality.qmd)
- [Results/5_Mapping_mortality.md](Results/5_Mapping_mortality.md)

This step maps the spatial pattern of inferred mortality risk across Goa using the filtered stranding records and a coastal grid.

## Data and outputs

The project stores the cleaned input datasets in the `Data/` directory and the processed analysis outputs in the `Results/` directory.

Key folders:
- `Data/`: cleaned data files, shapefiles, and survey inputs
- `Results/`: output tables, summary CSVs, and rendered Markdown reports
- `Code/`: analysis scripts and Quarto documents

## Notes for reproducing the analysis

- Open the QMD files in R or Quarto to reproduce the workflow step by step.
- The rendered Markdown files in `Results/` are intended for quick GitHub viewing and reference.
- Some analyses depend on intermediate outputs generated by earlier steps, so it is best to run the workflow in order from 1 to 5.

## GitHub-friendly report access

To browse the reports directly from GitHub, open the `Results/*.md` files listed above. Each file is generated from its corresponding QMD document in `Code/`.
